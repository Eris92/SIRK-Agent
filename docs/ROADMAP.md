# Roadmap

## v0.1.0 - First foundation

- plugin bootstrap
- `Pulpit -New` tab UI
- server-side session model and API
- WorkspaceHost .NET 8 executable
- named-pipe heartbeat protocol
- build script and CI
- basic architecture and build documentation

## v0.2.0 - MeshAgent bridge

- start WorkspaceHost on the selected node
- choose the active interactive Windows session
- forward heartbeat through MeshAgent
- stop and restart commands
- permission and token validation

## v0.3.0 - Diagnostics

- CPU, RAM and uptime
- last error and process exit code
- version, build and commit
- reconnect and stale-session handling

## v0.4+

- DXGI capture
- streaming
- input
- virtual display
- independent operator cursor
